# AI & Machine Learning Training

## Day 10
**Date:** 13 July 2026

### Topics Covered
- YData Profiling
- Sweetviz
- D-Tale
- Automated Exploratory Data Analysis (EDA)

### Summary

Today, I learned about **Automated Exploratory Data Analysis (EDA)** tools that help analyze datasets quickly and efficiently. We explored **YData Profiling**, which generates a detailed report containing dataset statistics, missing values, correlations, and data quality insights. We also learned **Sweetviz**, a visualization tool that creates interactive reports for comparing datasets and understanding feature relationships.

Another tool covered was **D-Tale**, which provides an interactive interface for viewing, filtering, sorting, and analyzing datasets directly in a web browser. These tools reduce the time required for manual data exploration and help identify issues before building machine learning models.

### Key Learning
- Understanding automated EDA tools.
- Generating comprehensive reports using YData Profiling.
- Creating interactive visualizations with Sweetviz.
- Exploring datasets interactively using D-Tale.
- Improving data analysis efficiency before model development.





## Day 11
**Date:** 14 July 2026

### Topics Covered
- Supervised Learning
- Classification
- Regression
- Train-Test Split
- Logistic Regression
- Model Training
- Model Evaluation
- Prediction using New Data

### Summary

Today, I learned about **Supervised Learning**, a machine learning approach where models are trained using labeled data. The trainer explained the complete workflow, including data collection, feature engineering, train-test splitting, model training, evaluation, and prediction. We also studied the two main types of supervised learning: **Classification**, which predicts categories, and **Regression**, which predicts continuous values.

We implemented a **Logistic Regression** model to predict student placement based on features such as CGPA, attendance, and study hours. We evaluated the model using accuracy and tested it with new student data. Additionally, we applied Logistic Regression to a **Teen Mental Health Dataset** to predict depression status based on factors like social media usage, sleep hours, academic performance, stress level, anxiety level, and addiction level.

### Key Learning
- Understanding the concept of supervised learning.
- Difference between classification and regression.
- Training and testing machine learning models.
- Using Logistic Regression for classification problems.
- Evaluating model accuracy and making predictions on new data.





## Day 12
**Date:** 15 July 2026

### Topics Covered
- Linear Regression (Introduction)
- Naïve Bayes Algorithm
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Model Evaluation
- Accuracy, Classification Report, and Confusion Matrix
- Algorithm Comparison

### Summary

Today, I learned about different **Supervised Machine Learning algorithms** used for classification problems. The session began with a brief introduction to **Linear Regression**, followed by **Naïve Bayes**, **K-Nearest Neighbors (KNN)**, and **Support Vector Machine (SVM)**. We understood their working principles, advantages, disadvantages, and real-world applications.

We implemented these algorithms on a **Teen Mental Health Dataset** to predict depression status. The models were evaluated using **Accuracy Score**, **Classification Report**, and **Confusion Matrix**, and we compared their performance to identify the most suitable algorithm for the given dataset.

### Key Learning
- Understanding Naïve Bayes, KNN, and SVM algorithms.
- Training and testing classification models.
- Evaluating models using accuracy, precision, recall, and F1-score.
- Comparing different machine learning algorithms.
- Selecting the best algorithm based on dataset characteristics and performance.

## Day 14
**Date:** 17 July 2026

### Topics Covered
- Decision Tree Algorithm
- Gini Impurity
- Entropy
- Information Gain
- Random Forest Algorithm
- Model Evaluation
- Feature Importance

### Summary

Today, I learned about **Decision Tree** and **Random Forest**, two important supervised machine learning algorithms used for classification tasks. The trainer explained how Decision Trees make predictions using **if-then-else** conditions and introduced concepts such as **Gini Impurity**, **Entropy**, and **Information Gain** for selecting the best feature splits.

We implemented both Decision Tree and Random Forest models on a **Teen Mental Health Dataset** to predict depression status. The models were evaluated using **Accuracy Score**, **Classification Report**, and **Confusion Matrix**. We also visualized the Decision Tree and analyzed **Feature Importance** in the Random Forest model to identify the most influential features.

### Key Learning
- Understanding the working of Decision Tree and Random Forest.
- Learning Gini Impurity, Entropy, and Information Gain.
- Training and evaluating classification models.
- Comparing Decision Tree and Random Forest performance.
- Analyzing feature importance for better model interpretation.
