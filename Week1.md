# AI & Machine Learning Training

## Day 3
**Date:** 2 July 2026

### Topics Covered
- Data Cleaning
- Missing Values
- Duplicate Records
- Text Data Cleaning
- Outlier Detection
- Outlier Removal
- Dataset Verification

### Summary

Today, I learned about **Data Cleaning**, which is the process of improving data quality before analysis. We discussed common data quality issues such as missing values, duplicate records, incorrect data types, inconsistent text formatting, outliers, and extra spaces.

I learned different methods to handle missing values, including removing rows and filling missing values using the **mean, median, and mode**. We also cleaned text data by removing extra spaces and standardizing text formatting.

The trainer explained how to detect outliers using **Box Plots** and the **Interquartile Range (IQR)** method. Finally, we verified the cleaned dataset using Pandas functions like `info()` and `describe()`.

### Key Learning
- Importance of data cleaning in Machine Learning.
- Handling missing values using different techniques.
- Removing duplicate records.
- Cleaning text data.
- Detecting and removing outliers.
- Preparing a clean dataset for analysis and model building.




# AI & Machine Learning Training

## Day 4
**Date:** 3 July 2026

### Topics Covered
- Univariate Analysis
- Multivariate Analysis
- GroupBy Function
- Crosstab
- Correlation Analysis
- Feature Engineering

### Summary

Today, I learned different techniques for analyzing data before building machine learning models. We studied **Univariate Analysis**, which focuses on analyzing a single variable, and **Multivariate Analysis**, which examines relationships among multiple variables.

The trainer demonstrated the **GroupBy** function in Pandas to summarize data, such as calculating the average CGPA for each department. We also learned about **Crosstab**, which shows the frequency distribution of different categories.

Another important topic was **Correlation Analysis**, which helps measure the strength and direction of the relationship between variables. Finally, we explored **Feature Engineering**, where new features are created from existing data to improve machine learning model performance.

### Key Learning
- Understanding univariate and multivariate analysis.
- Using GroupBy and Crosstab for data analysis.
- Measuring relationships using correlation.
- Creating new features through feature engineering.
- Importance of feature engineering in improving model accuracy.
