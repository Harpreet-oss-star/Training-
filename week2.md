- Feature Creation
- Feature Transformation
- Feature Scaling
- Feature Encoding

### Summary

Today, I learned about **Feature Engineering**, an important step in Machine Learning that involves transforming raw data into meaningful features to improve model performance. ### Key Learning
- Importance of feature engineering in Machine Learning.
- Creating new features from existing data.
- Transforming features to improve data distribution.
- Scaling data using StandardScaler and MinMaxScaler.
- Encoding categorical variables into numerical values.
- Using feature binning to categorize continuous data.




## Day 7
**Date:** 8 July 2026

### Topics Covered
- Principal Component Analysis (PCA)
- High Dimensional Data
- Dimensionality Reduction
- Standardization
- Explained Variance
- PCA Visualization
- Real-World Applications of PCA

### Summary

Today, I learned about **Principal Component Analysis (PCA)**, a dimensionality reduction technique used to reduce the number of features in a dataset while preserving most of the important information. The trainer explained the concept of **high-dimensional data** and how too many features can increase computation time, memory usage, and sometimes reduce model performance.

We standardized the dataset using **StandardScaler**, applied PCA to convert multiple correlated features into two principal components (PC1 and PC2), and analyzed the **explained variance ratio** to understand how much information was retained. Finally, we visualized the PCA results using a scatter plot and discussed its applications in face recognition, healthcare, finance, and recommendation systems.

### Key Learning
- Understanding the need for dimensionality reduction.
- Learning the concept of Principal Component Analysis (PCA).
- Reducing multiple features into principal components.
- Interpreting explained variance ratio.
- Visualizing reduced data using PCA scatter plots.
- Exploring real-world applications of PCA.




## Day 8
**Date:** 9 July 2026

### Topics Covered
- Imbalanced Data
- Random Oversampling
- Random Undersampling
- SMOTE (Synthetic Minority Over-sampling Technique)
- Tomek Links
- ADASYN
- SMOTE + Tomek Links

### Summary

Today, I learned about **Imbalanced Data**, a common problem in machine learning where one class has significantly more samples than the other. This can cause models to become biased toward the majority class and produce misleading accuracy. We visualized the class distribution and learned different techniques to balance the dataset.

The trainer explained and demonstrated **Random Oversampling**, **Random Undersampling**, **SMOTE**, **Tomek Links**, **ADASYN**, and **SMOTE + Tomek Links**. These methods help improve model performance by balancing class distributions and reducing bias during training.

### Key Learning
- Understanding the problem of imbalanced datasets.
- Learning oversampling and undersampling techniques.
- Using SMOTE and ADASYN to generate synthetic minority samples.
- Applying Tomek Links to remove overlapping data points.
- Improving machine learning model performance with balanced datasets.

- Z-Score Method

### Summary

Today, I learned how to identify patterns and anomalies in datasets using different data analysis and machine learning techniques. We explored **Pattern Detection** to discover relationships between variables and used **Group Comparison** to compare average CGPA across different departments.

### Key Learning
- Understanding pattern detection in datasets.
- Comparing data using GroupBy and Pivot Tables.
- Detecting anomalies using Z-Score and Isolation Forest.
- Learning K-Means clustering for grouping similar data.
- Identifying outliers to improve data quality and model performance.
